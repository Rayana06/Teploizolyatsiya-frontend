# Лабораторная работа №5

## Страницы приложения

### 1. Лента 

Страница последовательного просмотра теплоизоляционных материалов из mock-коллекции. На странице отображаются изображение, тип материала, название, описание, толщина, цена и количество отметок «Нравится».

Кнопка **«Следующая»** показывает следующий материал. Поля ввода отсутствуют.

### 2. Добавление 

Страница предназначена для добавления нового материала. В гостевом режиме она недоступна, поэтому пункт **«Добавление»** в нижней навигации отключён.

Кнопки и поля формы в лабораторной работе №5 не реализованы.

### 3. Плитка 

Страница выводит материалы из mock-коллекции в виде сетки карточек.

На странице расположены:

- поле-ползунок для выбора максимальной цены;
- кнопка **«Подобрать»** для применения фильтра;
- кнопка **«Подробнее»** в каждой карточке материала.

### 4. Вход 

Страница предназначена для авторизации пользователя. В гостевом режиме она недоступна, поэтому пункт **«Вход»** в нижней навигации отключён.

Поля логина и пароля, а также кнопка входа в лабораторной работе №5 не реализованы.
