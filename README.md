# Лабораторная работа №5 — SPA «Теплощит»

Фронтенд-приложение для гостевого просмотра теплоизоляционных материалов. Проект разработан на React и TypeScript, собран с помощью Vite, а интерфейс создан с использованием React-Bootstrap. Redux и Context не применяются.

Данные карточек поступают только из локальной mock-коллекции `src/data/materials.ts`. Если в объекте отсутствует ссылка на изображение или видео, компонент `MaterialMedia` подставляет локальный файл из каталога `public/default-media`.

## Запуск проекта

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

После запуска приложение доступно по адресу `http://localhost:5175`.

Проверка проекта:

```bash
npm run lint
npm run build
```

## Четыре страницы нижней навигации

### 1. Лента — `/`

Доступная гостю страница последовательного просмотра услуг из mock-коллекции.

На странице отображаются:

- изображение материала;
- тип теплоизоляции;
- название и краткое описание;
- толщина и цена за квадратный метр;
- количество отметок «Нравится».

Кнопка **«Следующая»** переключает текущую карточку на следующий объект mock-коллекции. После последнего объекта снова показывается первый.

### 2. Добавление — `/add`

Страница предназначена для создания новой услуги авторизованным пользователем. В лабораторной работе №5 приложение работает в гостевом режиме, поэтому пункт **«Добавление»** отображается в нижней навигации, но недоступен для нажатия.

Форма добавления и её поля в этой лабораторной не реализуются. Пункт помечен атрибутом `aria-disabled="true"`, а при наведении выводится подсказка **«Недоступно гостю»**.

### 3. Плитка — `/catalog`

Доступная гостю страница каталога. Услуги из mock-коллекции располагаются в виде сетки карточек.

Поля и элементы управления:

- ползунок **«Максимальная цена»** со значениями от 229,63 до 1 570,15 ₽/м²;
- кнопка **«Подобрать»**, применяющая выбранную максимальную цену;
- счётчик найденных материалов;
- кнопка **«Подробнее»** в каждой карточке.

Изменение ползунка само по себе не изменяет список. Фильтр применяется только после нажатия кнопки **«Подобрать»**. Компонент `CatalogFilters` получает выбранную цену, границы диапазона и функции обработки через props.

### 4. Вход — `/login`

Страница предназначена для авторизации пользователя. По условиям лабораторной работы №5 вход не реализуется, поэтому пункт **«Вход»** присутствует в нижней навигации, но недоступен гостю.

Поля логина, пароля и кнопка отправки формы отсутствуют. Пункт помечен атрибутом `aria-disabled="true"` и имеет подсказку **«Недоступно гостю»**.

## Вложенная страница материала — `/materials/:materialId`

Страница открывается по кнопке **«Подробнее»** из каталога и показывает выбранную услугу из той же mock-коллекции.

На странице находятся:

- кнопка **«Назад»**;
- изображение и видеоролик;
- тип, название и производитель материала;
- описание, толщина, цена и назначение;
- дата публикации и количество отметок «Нравится».

Параметр `materialId` считывается из URL с помощью `useParams`. Если объект с указанным идентификатором отсутствует, выводится сообщение **«Материал не найден»** и кнопка **«Вернуться в каталог»**.

## Нижняя навигация

Панель `BottomNav` закреплена внизу и содержит четыре пункта:

| Пункт | Маршрут | Состояние для гостя |
|---|---|---|
| Лента | `/` | доступен |
| Добавление | `/add` | недоступен |
| Плитка | `/catalog` | доступен |
| Вход | `/login` | недоступен |

## Основные компоненты и props

- `MaterialCard` получает объект `material` и вариант отображения `feed | tile`.
- `MaterialMedia` получает ссылки на изображение и видео, название материала, признак показа видео и компактного режима.
- `MaterialFacts` получает объект услуги и признак компактного отображения.
- `CatalogFilters` получает `price`, `minPrice`, `maxPrice`, `onPriceChange` и `onApply`.
- `BrandHeader` и `BottomNav` не принимают props.

## Используемые хуки

| Хук | Назначение |
|---|---|
| `useState` | текущая карточка ленты, значения фильтра, состояние видео |
| `useMemo` | вычисление отфильтрованного списка материалов |
| `useEffect` | изменение заголовка вкладки, анимация и прогресс видео |
| `useRef` | ссылки на видео, контейнер и объект анимации |
| `useParams` | получение идентификатора материала из URL |
| `useNavigate` | возвращение на предыдущую страницу |
