# Лабораторная работа №6 — React + Redux Toolkit

Это репозиторий фронтенда. История ЛР5 находится в ветке `main`, продолжение ЛР6 — в ветке `lab6`. Бэкенд находится в отдельном репозитории [Teploizolyatsiya](https://github.com/Rayana06/Teploizolyatsiya), ветка `lab6`.

Тема: оценка эфективности теплоизоляции здания. Услуга — карточка теплоизоляционного материала.

Реализовано:

- Redux Toolkit: `auth`, `filters`, `materials`; thunk middleware подключён `configureStore` по умолчанию;
- ценовой слайдер ЛР5 сохранён в Redux: выбранная цена переживает переходы между страницами, а применённое значение передаётся в query backend;
- цена за квадратный метр видна и на каждой карточке плитки;
- гостевой fallback на mock при недоступном backend;
- вход/выход ручным Axios без thunk и кодогенерации;
- услуги через тематически названные thunk и Orval/Axios-клиент из OpenAPI;
- два состояния добавления: «Далее» создаёт черновик с названием и медиа; «Опубликовать» заполняет его поля и публикует, после чего материал появляется в каталоге; также доступны логическое удаление и лайки;
- предварительный просмотр изображения и видео сразу после выбора файла;
- блокирующая AJAX-анимация;
- proxy `/api` → backend, `/silo` → MinIO и `/insulation-materials-assets` → статика backend.

## Запуск

1. Клонировать рядом репозиторий бэкенда `Teploizolyatsiya`, переключиться в нём на ветку `lab6`, затем выполнить `docker compose up -d` и `npm start`.
2. В этой папке: `npm install`, `npm run dev`.
3. Открыть `http://localhost:5176`.
4. Демо-вход: `user1@teploshchit.local` / `Teplo123!`.

Для повторной кодогенерации: `npm run api:generate`. Исходная схема — `openapi/lab6.json`, результат — `src/api/generated`.

При запуске backend применяется миграция с ценой, брендом и назначением материалов. Исходные 7 полей списка и 9 полей ленты ЛР3 сохранены для прежних запросов. React передаёт `view=rich` для полных карточек и `maxPriceRubM2` для серверного фильтра. Черновик загружается через `GET /api/insulation-materials/draft`, первый этап выполняет `POST /draft/start`, второй — `PATCH /draft/:id` и `PUT /:id/publish`.

Если в старой базе остались только два демонстрационных материала, выполнить файл `database/lab6-restore-catalog.sql` из репозитория бэкенда через Adminer или `psql`: скрипт без перезаписи добавляет шесть материалов ЛР5. Материалы без указанной цены видны в общем списке; после применения ценового ограничения они не включаются в результат.
