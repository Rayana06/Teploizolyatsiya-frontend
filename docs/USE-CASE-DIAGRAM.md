# Диаграмма прецедентов React-интерфейса

Редактируемая диаграмма: [Диаграмма-прецедентов-React.drawio](./Диаграмма-прецедентов-React.drawio). Иллюстрация для отчёта: [use-case-diagram.png](../report-assets/use-case-diagram.png).

Диаграмма показывает только действия с кнопками и навигацией, которые есть в приложении. Гость открывает «Ленту», «Плитку» и «Вход»; в ленте нажимает «Следующая» или «Подробнее», в каталоге — «Подобрать» и «Подробнее», на странице входа — «Войти». Пользователь дополнительно открывает «Добавление», выбирает файлы, нажимает «Далее» и «Опубликовать», ставит лайк, удаляет свой материал и выходит кнопкой «Выход».

Внутренние детали реализации (Redux, mock, запросы к серверу) в эту диаграмму не включены: это не кнопки и не переходы пользователя.
